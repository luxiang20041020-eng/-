# ONE 泰拳格斗馆小程序｜管理员使用说明

版本：2026 年 10 月 8 日 · 适用对象：场馆管理员、前台负责人、兼任教练的管理员

本说明对应项目当前代码中的功能。使用前请由项目负责人确认小程序和业务服务已同步更新；旧发布版本的页面可能与本说明不同。

## 1. 先了解你的管理入口

管理员既有经营管理权限，也可以充当教练。登录后，底部主要入口为：首页、预约、工作台、看板、我的。

| 入口 | 主要用途 |
| --- | --- |
| 首页 | 查看门店资料、训练介绍和套餐展示 |
| 预约 | 查看团体／专属训练场次，筛选门店、日期和教练 |
| 工作台 | 权益派发、本人排期、课程名单、到场及人工核销 |
| 看板 | 查看当前门店当日数据，进入人员、套餐和门店管理 |
| 我的 | 查看个人资料、权益、训练记录和退出登录 |

日常操作顺序通常是：确认门店 → 学员登录或管理员录入建档 → 线下收款并派发权益 → 发布排期 → 确认到场或人工核销 → 查看当天记录。

## 2. 登录与账号准备

1. 打开小程序，进入“手机号快捷登录”。
2. 如出现 ONE 隐私保护提示，阅读协议后选择“同意并继续”。
3. 点击“手机号快捷登录”，完成手机号授权。
4. 确认“工作台”和“看板”入口可见。

首次管理员账号由项目负责人配置。普通手机号首次登录通常成为客户账号，其他人员之后可由管理员调整身份。系统首次使用会自动准备基础数据，登录前无需先进入管理页或点击“检查数据库”。

给新客户派课前，可以请客户用本人手机号登录建档，也可以由管理员在“人员权限”页手动录入姓名、手机号和门店。手动录入后即可派课，无需等待客户首次登录。

## 3. 人员权限管理

入口：“看板” → “人员权限管理”，进入后页面标题为“人员权限”。

### 查找人员

1. 搜索姓名、手机号或门店名称。
2. 按需要选择“客户”“教练”“管理员”。
3. 可进一步筛选“正常账号”或“停用账号”。
4. “重置筛选”恢复全部人员。

卡片展示姓名、手机号、角色、账号状态、所属门店和权限范围。顶部人数为各身份总人数，列表人数为当前筛选结果。

### 手动录入新用户

1. 点击右上角“＋ 录入新用户”。
2. 填写客户姓名（最多 20 个字）和本人 11 位手机号。
3. 选择所属门店，仅可选择营业中的门店。
4. 点击“保存用户档案”，成功后列表会定位到新用户。
5. 如需给客户加课，进入“工作台 → 权益派发”按姓名或手机号搜索。

新档案身份为客户；需要教练或管理员功能时，在人员列表中调整权限。建档不会自动增加课时，也不会绑定录入人的微信账号。客户之后使用相同手机号授权登录，沿用原档案、权益和训练记录。

重复手机号会提示“该手机号已建档”，请在列表核对已有档案。录入失败时表单会保留，可修正后再保存；网络异常后可在同一表单重试。没有可用门店时，请先在门店管理中启用门店。

### 查看每个客户的剩余套餐

在“看板 → 人员权限管理”找到客户，卡片的“剩余套餐”显示当前可用团课和私教次数；点击“查看详情”可查看两类课时的有效期、状态，以及最近 30 条套餐派发记录。

同类型套餐的课时合并使用，剩余次数按团课／私教统计；派发记录保留原套餐名称、增加次数、金额和本次到期日。未购课、已用完和已过期会分别标明，过期次数不计入可用余额。旧派发记录没有保存到期日时显示“未记录”。停用客户也可查看余额，页面会提醒账号状态。

点击“刷新套餐余额”读取最新记录。加载期间显示读取状态；读取失败会显示具体原因和重试入口，不会把失败显示为零课时。

### 调整身份权限

1. 找到目标人员，核对姓名和手机号。
2. 点击“调整权限”。
3. 阅读角色说明并选择新身份。
4. 点击“确认变更权限”，再次核对人员和身份变化。
5. 确认成功后，卡片及人数会更新。对方可重新进入小程序，必要时重新登录，以刷新功能入口。

| 身份 | 可使用的功能 |
| --- | --- |
| 客户 | 浏览训练、预约课程、查看个人权益和记录 |
| 教练 | 客户功能，以及排期、课程核销、学员权益派发 |
| 管理员 | 教练功能，以及人员权限、套餐、门店管理和运营看板 |

当前登录管理员的自身权限受到保护，不能在本页撤销。身份变更不改变已有课时和预约；对停用账号改权也不会启用账号。本模块展示和筛选账号状态，但没有停用／启用账号的操作按钮。

## 4. 套餐新建与上下架

入口：“看板” → “套餐上下架”，进入后页面标题为“套餐管理”。

### 查看套餐

通过名称搜索、上架状态和团课／私教类型筛选。每张套餐卡片显示课时数、展示价、默认有效期和上架状态。

### 新建套餐

1. 点击右上角“＋ 新建套餐”。
2. 填写名称，选择团课或私教。
3. 填写课时数、展示价和默认有效期。
4. 决定是否开启“创建后立即上架”。默认保持下架，可核对后再上架。
5. 点击创建按钮，核对确认弹窗，提交。

名称最多 60 个字；课时数为 1～10000 的整数；有效期为 1～3650 天；价格可为 0，最多两位小数。切换套餐类型会将默认有效期重设为团课 180 天、私教 365 天，可再按实际方案修改。

### 上架或下架

1. 在目标套餐卡片点击“重新上架”或“下架套餐”。
2. 核对套餐名称、课时和价格，再确认操作。
3. 成功后状态和统计立即更新；在状态筛选下，卡片可能移出当前列表。

上架后，套餐可在首页展示并用于权益派发。下架后停止展示和新派发，学员已经获得的课时仍按其原有权益规则使用。当前页面提供新建和上下架功能，没有编辑或删除已有套餐的入口。

## 5. 权益派发：记录线下收款并给学员加课

入口：“工作台” → 权益派发入口，进入“权益派发”页面。收款在线下完成，小程序记录实际收款并增加权益。

### 第一步：选学员

输入姓名或手机号，核对号码后选中。页面显示学员当前团课、私教余额；选择后进入套餐步骤。

### 第二步：选套餐

按“全部／团课／私教”筛选，选择套餐，再点击“下一步 · 记录收款”。系统自动填写标准金额和到期日期。

### 第三步：收款与核对

1. 按实际收款修改金额，最多两位小数。
2. 选择收款方式：微信转账、支付宝、现金、银行卡、赠课或其他。
3. 选择“赠课”时金额自动设为 0；赠课提交时金额须为 0。
4. 核对或调整权益到期日，填写备注（选填）。
5. 阅读“派发前核对”：当前可用、增加课时、预计到账余额、到账有效期及实收金额。
6. 点击“确认派发权益”，核对学员姓名、手机号、套餐和金额，再确认。
7. 看到“权益已派发”回执后，本次操作完成；可点击“继续派发”处理下一位学员。

同类型有效课时会合并，到账有效期保留新旧日期中较晚的一项；已过期课时不随续费恢复。核对页余额是预计值，实际记录以成功写入时为准。

失败时选择和表单会保留。若网络中断、结果无法确认，请先查看看板派发记录及学员余额，确认是否已到账，再决定是否重新派发。

## 6. 排期管理：以管理员身份执教

入口：“工作台” → 排期入口，进入“排期管理”。这里显示本人在所选门店的课程；管理员可以用自己的账号担任教练。需要其他教练发布本人课程时，请其使用自己的账号排期。

### 查看排期

1. 在顶部确认门店，需要时点击“切换”。
2. 周日历显示每天场次数；点击某一天查看该日课程。
3. 使用“上周／下周”“选择日期”或“今天”定位日期。
4. 可按全部、团课、私教筛选。
5. 点击课程上的“名单与核销”查看学员名单。

若出现日期信息不完整或同步失败提示，点击“重新同步”或下拉刷新，不能将提示当作没有课程。

### 新增排期

1. 选定日期，点击“＋ 新增排期”。
2. 填写训练主题、类型、日期及开始／结束时间。
3. 团课设置人数上限，范围为 1～100；私教为 1 对 1。
4. 如开启“每周重复”，系统将发布所选日及随后 3 周同一星期、同一时段的课程，共 4 场。
5. 核对具体发布日期、时段及人数，再确认发布。

开始时间须在未来，结束时间须晚于开始时间。同一教练跨门店的时间重叠也会在发布时校验。当前页面不提供已发布课程的编辑或撤销入口。

## 7. 到场核销与缺席登记

入口：工作台“今日训练”中的课程，或排期管理中的“名单与核销”。

1. 核对课程主题、日期、时间和门店。
2. 在预约名单中核对学员姓名和手机号。
3. 实际到场后点击“确认到场”。
4. 未到场的学员可点击“标记缺席”，阅读提示后确认。

小程序预约时已经扣减对应类型 1 课时，确认到场不再扣一次。标记缺席不会自动返还已扣课时。已核销或已缺席的记录不能再次处理；当前页面不提供撤销核销或修改已确认状态的按钮。

管理员可处理可访问课程名单；教练只可处理自己负责的场次。客户的身份码用于展示和核对身份，出示二维码本身不会自动完成扣课或核销。

## 8. 线下人工预约的学员怎么核销

学员不必在小程序预约，但须已登录建档或由管理员手动录入，并具有对应类型的有效课时。

### 情况一：参加已有排期，但不在预约名单中

1. 打开本场课程的“到场核销”页面。
2. 点击“补核销线下学员”。
3. 输入至少两个字的姓名或手机号，点击搜索，选中学员。
4. 核对本场信息，填写备注（选填）。
5. 点击“确认到场并核销”，核对后提交。

无预约的学员扣减本类型 1 课时；若已有待核销预约，直接确认到场，不重复扣课。场次须已开始且未取消，未预约的补核销还会检查人数上限。

### 情况二：单独登记线下训练，没有预先排课

1. 进入“工作台” → “人工核销”。
2. 搜索并选定已建档学员。
3. 选择团课或私教，填写实际训练日期和时间。
4. 核对当前门店及执教账号，填写备注。
5. 确认后扣减对应类型 1 课时，并保存训练记录。

只能登记已发生的训练，不能填写未来时间。同一学员、门店、类型和同一训练分钟的重复独立登记会被拦截。

如果显示“本次核销结果待确认”，使用“重试并核对核销结果”继续原请求，不要改换学员或训练时间。系统会复用原请求，避免重复扣课；重新进入页面后仍可核对待确认请求。

## 9. 门店与经营数据

### 门店管理

入口：“看板” → “门店管理”。可新增门店、编辑名称和地址、填写地图坐标，并停用或恢复营业。停用门店会从首页和预约选择中移除，历史人员及排课数据保留。

### 查看看板

确认看板顶部当前门店。页面显示该门店当天的线下实收、到场核销、新增团课和私教课时。

展开“权益派发记录”可查看操作人、学员、套餐、金额、备注和收款方式；“复制记录”复制当前展示内容，便于粘贴整理，并非导出完整历史账单。“最近人工核销”展示线下训练登记情况。

“检查服务”用于检查及补齐基础配置，不是每天营业或登录前的必做步骤。

## 10. 常见问题

操作提示会说明可确认的具体原因，例如手机号已建档、课时已过期、课时已用完、账号停用、场次满员、网络中断或请求超时，并给出下一步处理方式。较长提示会完整展示；内部技术信息由项目负责人查看。

写入遇到网络中断或超时时，页面可能提示“结果尚未确认”：录入客户、人工核销应使用原表单／原请求重试核对；其他操作先刷新相关记录核对，避免重复提交。操作成功后刷新失败，会分别说明保存结果和刷新问题。

| 问题 | 处理方法 |
| --- | --- |
| 搜不到新学员 | 请学员用本人手机号登录，或在人员权限页录入新用户；核对姓名或号码后重试。人工核销搜索至少两字 |
| 看不到管理入口 | 确认登录的是正确手机号；让管理员核对身份，必要时重新登录 |
| 角色降为客户后又恢复管理员 | 联系项目负责人检查管理员账号配置 |
| 派发后客户仍看不到课时 | 先核对手机号、套餐类型和回执；让客户下拉刷新“我的”，并查看派发记录 |
| 当天课程不显示 | 核对门店、日期、团课／私教筛选及是否为本人排期，再点击重新同步 |
| 人工核销提示余额不足或已过期 | 先核对对应类型权益；需要补课时的，应完成线下收款和权益派发 |
| 误派发、误核销、误标缺席 | 管理员进入“看板 → 操作纠错”，核对原记录和余额，填写原因后撤销；缺少原余额快照的旧派发记录须人工核对 |
| 退出登录失败 | 检查网络后重试；仍失败时记录错误提示并联系项目负责人 |

退出入口：“我的”页面底部 → “退出登录” → 确认。退出不会删除账号、课时或训练记录。公共设备使用完毕后应退出自己的账号。

## 11. 每日操作速查

| 时段 | 操作 |
| --- | --- |
| 营业前 | 确认门店和本人当日排期，检查套餐上架状态 |
| 收款后 | 核对学员手机号，完成权益派发，确认成功回执 |
| 训练到场 | 已预约学员确认到场；线下预约按对应方式人工核销 |
| 训练结束 | 核对待核销名单，确认实际缺席人员 |
| 收工前 | 查看当日派发和核销记录，核对实收，退出公共设备上的账号 |

## 多语言界面

在“我的 → 语言设置”选择简体中文、英语、法语、泰语、德语、日语或印地语（Hindi）。客户、教练和管理员均可使用，登录页面也有语言入口。页面、状态和操作提示随语言切换，姓名、门店、地址、课程、套餐名称与备注保持录入原文；权限、余额和业务记录不受语言设置影响。选择保存到当前设备，重新登录后仍生效。

## 排课修改、取消与操作纠错

在“工作台 → 排期管理”的场次卡片点击“调整 / 取消”，先核对受影响客户，填写操作原因，再保存日期、时间、主题或人数上限。更换教练仅管理员可操作，系统会检查教练时间冲突。调整单个场次，不批量改动每周重复生成的其他场次。

取消场次会自动退还待核销预约各1课时。若网络故障导致退课未完成，重新进入该场次点击“继续退课”；不要另行派课补偿，以免重复。已开始或有核销／缺席记录的场次不能直接取消。

管理员进入“看板 → 操作纠错”，选择原派发或核销记录。确认客户、当前余额和预计变化，填写原因后撤销；下方审计记录保留操作人、原因与前后余额。预约到场／缺席纠错只恢复待核销，课时仍被预约占用；直接人工核销纠错则退回课时并作废训练记录。

派发撤销只调整课时，不自动退还线下款项。课时已使用导致余额不足，或后续操作改变有效期时，先核对相关记录。历史派发没有原余额快照时不提供自动撤销，避免恢复错误余额。


## 客户跟进与经营报表

管理员进入“看板 → 客户跟进与报表”，切换客户跟进和经营报表。客户按所属门店筛选；没有所属门店的旧档案按有效派发所在门店关联。停用账号不进入名单，最近到店在全部门店的有效到场记录中核对。

默认提醒未来7天内到期且仍有余课、已购类型有效余额不超过2次、距最近到店或建档超过30天的客户；可修改阈值，也可查看全部客户、按姓名或手机号搜索。未购课类型不误报余额不足，已过期课时显示为不可用。名单展示团课和私教余额、到期日、最近到店日期，并可复制手机号。

经营报表按北京时间的日期范围查询（含首尾日，最多366天）。收款以线下派发的实收金额和登记日期统计；已撤销和零金额赠课不计收入。续费为同一客户同一课种的后续付费购买，历史跨门店购买参与判定；历史顺序无法确认时单独标识。核销、缺席按实际训练日期统计，取消或已撤销核销不计入。教练报表展示排课、取消、已完成、到场、人工核销和授课分钟；授课时长仅计算已结束且有到场的正式排课，独立人工训练只计人次。历史记录缺少日期会提示，并从对应统计排除。读取失败不显示虚假的零收入。

“导出 CSV”生成当前完整查询结果，包含全部符合条件的客户，或经营汇总、每日数据、教练情况及收款明细，不受页面每次展示30条限制。表头使用当前语言，用户录入内容保持原文。文件通过微信文件选择界面分享；不支持文件导出的设备可“复制表格”粘贴到Excel。公式开头的文本按普通文本保护，手机号前导零保留。条件变化后先重新查询，再导出。


## 自选时间的专属预约与限期无限次套餐

专属训练现在由客户在“预约 → 专属训练”查看全部启用的教练（沿用教练、管理员可授课的设置），选择教练和未来七天内的日期，再自行选择同一天的开始、结束时间。结束须晚于开始，不限于60分钟。页面展示该教练当天已占用时间；服务器检查全部门店的教练冲突及客户已有预约。无须先发布私教课，预约成功自动建立1人专属场次，出现在客户预约、教练排期和核销名单。客户仍需私下与教练确认安排，系统不代发消息。取消沿用开课前超过2小时的规则，取消后释放时间；原已发布场次和已有预约保留历史。

专属预约写入前将原请求保存到当前账号的本机记录；网络结果不明时显示“核对原预约”，复用原请求确认，不可改动原请求时间。已确认的业务失败释放请求，允许重新选择。后台幂等记录避免重试产生额外场次或扣课。

管理员“套餐管理 → 新建套餐”可选择团课／私教，再选择“按次数”或“期限内无限次”。无限次无需填次数，但须填写价格和有效天数；派发页仍可核对实际到期日。无限次权益从派发当天生效，到期日当天可用。重复派发保留新旧无限次到期日中较晚日期，次数与无限次分别保留有效期，不互相覆盖。按实际训练日期判断期限，优先使用有效无限次权益；到期后仅可使用仍有效且有余额的次数权益。

预约、人工核销、客户退约、场馆取消与误核销纠错按原记录实际消费方式处理。无限次不扣次数，取消也不增加次数；之前用次数预约的课，后来购买无限次套餐，取消仍退还当时扣掉的次数。调整日期不可超出该预约的权益期限。无限次误派发在未使用且没有较新无限次派发时可撤销，恢复原期限并保留审计；已用于预约或核销时提示先核对训练记录。无限次套餐在首页、我的、客户详情、派发、客户跟进、经营报表和CSV中分别展示，实收与续费仍正常统计。


## 教练公开资料与头像

教练和可授课管理员在“我的 → 我的教练资料”编辑本人资料。“基本资料”填写头衔、资历和擅长，“介绍与荣誉”填写介绍及荣誉，“照片与证书”上传最多6张图片。切换分区保留未保存的内容，最终点击“保存教练资料”统一保存。擅长与荣誉每行一项、最多10项；照片点击放大，点击缩略图右上角“×”移出相册。上传后的文字和相册需要保存才公开；头像单独上传后立即生效。普通客户也可在“我的”上传头像。

资料保存失败会保留草稿，旧页面与新资料发生冲突时须重新读取后编辑；重新读取会确认是否丢弃未保存内容。客户从专属训练教练列表进入介绍页；已停用、删除或变为客户的账号不再展示为教练。照片必须由当前账号上传，不能编辑其他人的介绍。
