# 页面背景资源

本次使用 imagegen 内置图像生成工具制作三张独立照片背景，未使用 CLI 生成。图片为生成的视觉素材，不对应实际门店、教练或客户；没有加入文字、标志或水印，页面文字由小程序和七种语言文案显示。

## 使用位置与文件

| 背景 | 部署文件 | 位置 |
| --- | --- | --- |
| 拳馆空间 | [gym-header.jpg](../miniprogram/images/backgrounds/gym-header.jpg) | 预约、工作台、管理看板顶部 |
| 团体训练 | [training-group.jpg](../miniprogram/images/backgrounds/training-group.jpg) | 可预约团体场次卡片顶部 |
| 一对一训练 | [training-private.jpg](../miniprogram/images/backgrounds/training-private.jpg) | 专属训练教练选择模块；历史专属场次卡片使用同图 |

部署文件为 768 × 512 JPEG，三张共 120586 字节（约 118 KB）。原图保存在 [artifacts/generated-backgrounds](../artifacts/generated-backgrounds)，不会进入小程序代码包。首页和“我的”维持原有视觉。

## 生成提示词与原图

完整原始提示词见 [prompts.json](../artifacts/generated-backgrounds/prompts.json)，原图与压缩参数见 [assets.json](../artifacts/generated-backgrounds/assets.json)。

- 场馆空间：现代拳馆、拳台和沙袋，暖色侧光；左侧留出深色空间，供页面标题叠加。
- 团体训练：四名成年学员一起练习拳击／泰拳基础动作；人物集中在中右侧，适配横向场次卡片。
- 专属训练：一名女教练持靶指导一名男学员，明确表现一对一教学；人物集中在中右侧。

均要求纪实照片风格、自然身体比例、无文字和品牌标志。保留原始 PNG，部署版本仅缩小尺寸并压缩为 JPEG。

## 布局与发布

顶部图片为独立装饰层，以深色底色和渐变遮罩保证标题清晰。团训与私教素材选择上部的人物区域显示；课程详情、人数和预约按钮保留在白色内容区。图片不承担点击事件，门店选择及预约操作仍由原有文字和按钮触发。

三个 JPEG 随代码打包，重新编译并上传小程序即可使用。发布前仍按开发者工具代码包分析核对最终编译体积。
