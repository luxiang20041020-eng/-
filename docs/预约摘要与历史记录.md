# 预约摘要与历史记录

「我的 → 我的预约」最多展示最近创建的3条待到店预约，不展示已完成、已取消或已缺席记录。没有待到店预约时展示预约引导，「全部预约」入口始终保留。

「全部预约」独立页面支持全部、待到店、已完成、已取消、已缺席筛选。每页20条，向下滚动或点击「加载更多」读取下一页；失败保留已加载记录并允许重试，下拉刷新重新从第一页读取。符合取消条件的记录可直接取消，成功后刷新并清理个人中心和预约大厅缓存。

接口 `getMyBookingRecords` 根据微信身份查询个人记录，忽略客户端传入的客户ID。按创建时间和记录ID倒序分页，每次仅查询21条以判断是否有下一页，只读取本页课程详情。历史数据和训练统计保留。旧个人中心缓存也会在前端过滤并限制为3条。

上线需部署 `businessCore` 并编译发布小程序。无需新建集合。本轮仅本地验证，未调用或部署线上服务。
