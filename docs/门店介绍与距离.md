# 门店介绍与距离

首页顶部门店入口打开门店列表，展示实景、地址、营业时间和距离。点击卡片查看介绍、地图位置、到店指引、联系电话和相册；查看详情不切换当前门店，点击底部选择按钮才切换。首页底部地址区域也可进入当前门店详情。

管理员在「看板 → 门店管理 → 编辑资料」填写介绍、营业时间、联系电话及到店指引。地图选点会更新详细地址和坐标；手填坐标需为 GCJ-02，且必须同时填写经度和纬度。首页图片仍在「首页实景图片」入口管理。介绍及其他录入内容保留原文，操作界面支持现有7种语言。

仅用户主动点击「查看距离」或「刷新距离」时调用定位。先完成小程序隐私授权，再由微信请求定位权限；拒绝或取消仍可选店。位置仅用于当前页面计算直线距离，缓存5分钟，不写入本项目的本地存储或云端。定位后近处门店优先展示，未填坐标的门店排在后面；行车路线通过微信地图查看。

上线需重新部署 `businessCore` 并重新编译、发布小程序。无需新建集合。`biz_store` 新增可选字段 `introduction`、`business_hours`、`contact_phone`、`arrival_tips`；旧客户端仅修改基本资料时保留这些字段，新的空字符串可清空字段。

定位接口已在 `app.json` 的 `requiredPrivateInfos` 中声明 `getLocation`、`chooseLocation`，并填写 `scope.userLocation` 用途。上线时请同步微信后台隐私保护指引中的位置信息用途，并确认定位接口可用。配置参照[微信官方示例](https://github.com/wechat-miniprogram/miniprogram-demo/blob/master/miniprogram/app.json)，地图坐标参照[腾讯位置服务说明](https://github.com/TencentLBS/tencentmap-miniprogram-skill/blob/main/quick_start_and_best_practices.md)。

本地通过业务与前端回归、微信原生模板和样式编译、七种语言及320/375/430px布局检查。浏览器预览中的地图仅为布局示意；实际定位权限、门店地图、导航与拨号仍需在微信真机验证。本轮未部署或调用线上服务。
