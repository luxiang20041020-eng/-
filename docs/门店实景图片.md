# 门店实景图片

管理员进入「看板 → 门店管理」，在对应门店点击「首页实景图片」。支持添加、更换、删除照片，填写最多40字的图片说明，最多6张；点击「保存门店图片」后更新该门店首页的「在这里，认真训练」模块。照片按列表顺序显示，点击可查看大图。

未配置的门店继续显示原有三张默认图片。「恢复默认图片」会修改当前草稿，仍需保存；删除全部图片并保存则隐藏该门店的实景模块。取消编辑不会改变首页。

上传使用现有相册隐私授权及图片压缩流程，图片存储于云存储，不计入小程序代码包。上传失败保留已有草稿；保存检查当前管理员身份、文件来源及门店图片版本，同时编辑发生冲突时提示重新打开图片管理。其他管理员可以保留此门店已有的图片。

上线需要重新部署完整的 `cloudfunctions/businessCore`（包括新增的 `store-gallery.js`），并重新编译、发布小程序。新增接口 `updateStoreGallery` 仅管理员可用；无需新建集合。门店记录新增 `home_gallery`、`gallery_version`、`gallery_updated_by` 字段。

沿用头像/教练相册的云存储权限：管理员可上传本人 `profile-media/<账号哈希>/` 目录下的图片，首页访客可读取已展示的门店图片。上线后需在实际微信环境验证一次上传与游客浏览，因为本地测试使用模拟云存储。

本地验证：业务与前端回归、微信原生 WXML/WXS 与 WXSS 编译、7种语言及320/375/430px布局检查。布局预览使用示例数据，不操作真实云环境。
