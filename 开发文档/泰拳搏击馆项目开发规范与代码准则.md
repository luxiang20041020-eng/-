# **🥊 泰拳搏击馆小程序：开发规范与代码准则 (V1.0)**

## **一、 技术栈选型**

- **基础框架**：Taro ( React + TypeScript 模式)
- **样式处理**：Tailwind CSS (通过 taro-plugin-tailwindcss) 或 Scss (BEM 命名法)
- **状态管理**：轻量级使用 React Context 或 Zustand；复杂场景使用 Redux
- **后端支撑**：微信小程序·云开发 (Cloud Development) 

## **二、 项目目录结构规范**

清晰的目录结构是维护的基础，建议采用功能模块化布局：

src/\
├── assets/          # 静态资源（图标、背景图、泰拳馆宣传图）\
├── components/      # 公共组件（按钮、课程卡片、核销弹窗）\
├── constants/       # 常量定义（角色枚举、预约状态、API 路径）\
├── hooks/           # 自定义 Hook（如 useAuth, useCountdown）\
├── pages/           # 页面目录\
│   ├── index/       # 首页\
│   ├── booking/     # 预约相关\
│   └── profile/     # 个人中心（含登录页）\
├── services/        # 网络请求与 API 接口封装\
├── utils/           # 工具函数（日期格式化、扫码解析、权限校验）\
├── app.config.ts    # 全局配置（页面路径、导航栏、权限声明）\
└── app.tsx          # 入口文件（云开发初始化、全局登录态拦截）

## **三、 命名与编码风格**

### **1. 变量与函数**

- **变量名**：小驼峰 camelCase（例：isCoach, scheduleList）
- **常量名**：全大写蛇形 UPPER\_SNAKE\_CASE（例：ROLE\_ADMIN: 3）
- **布尔值**：建议以 is, has, should 开头（例：hasVipCard）

### **2. 组件命名**

- **文件命名**：大驼峰 PascalCase（例：CourseCard.tsx）
- **Props 传递**：必须定义 interface 进行类型约束。

### **3. 注释规范**

- **接口注释**：所有从 services/ 导出的 API 函数必须标注对应文档的接口编号（例：// @API 1.1 手机号一键登录）。
- **业务注释**：复杂的业务逻辑（如课时核销计算、教练排课冲突检测）必须写明原因。

## **四、 接口 (API) 与数据规范**

### **1. 请求拦截器 (Interceptors)**

必须在 services/request.ts 中统一处理：

- **Token 注入**：从 Storage 读取 Token 并放入 Header 的 Authorization。
- **401 拦截**：发现 Token 过期，自动跳转至 /pages/profile/login。
- **500 报错**：统一使用 Taro.showToast 弹出 msg。

### **2. TypeScript 接口定义**

所有 API 的响应数据必须有对应的类型定义，严禁在业务逻辑中大量使用 any。

// 示例：课程排期类型\
interface ISchedule {\
id: number;\
title: string;\
class\_type: 1 | 2; // 1-团课 2-私教\
startTime: string;\
coachName: string;\
currentCapacity: number;\
}

## **五、 业务逻辑核心规范**

### **1. 登录与权限保护**

- **静默登录**：App 启动时在 app.tsx 检查 Token 有效性。
- **路由守卫**：预约页面、教练核销页面必须判断 role 权限。
- **手机号登录**：严格遵循微信最新规范，使用 getPhoneNumber 插件式调用。

### **2. 日期与时间处理**

- **统一格式**：前端显示统一使用 YYYY-MM-DD HH:mm。
- **时区处理**：存储统一使用 ISO 字符串或时间戳，避免跨时区导致课时表错乱。

### **3. 扫码核销逻辑 (安全增强)**

- **动态码**：用户展示的核销码应包含 userId + 时间戳 + 随机盐 的加密串。
- **时效性**：核销码有效期建议设为 30 秒，防止截图作弊。

## **六、 性能优化规范**

1. **图片优化**：泰拳馆的高清照片必须经过压缩，或使用云存储的 imageMogr2 进行缩略处理。
2. **分包加载**：将“教练端管理页面”放入独立分包，减少首页首屏加载时间。
3. **防止双击**：所有提交订单、确认核销的按钮必须做 loading 状态控制，防止重复扣课时。\
