# **🥊 泰拳搏击馆小程序：核心页面原型与交互设计 (Wireframes)**

本文档使用文本线框图展示了小程序的核心页面布局与组件层次。请 UI 设计师和前端开发以此作为页面骨架搭建的基准。

## **📱 0. 全局底部导航栏 (TabBar) 动态渲染**

根据用户登录后返回的 role 字段动态显示底部 Tab：

- **客户 (Role=1)**: 🏠 首页 | 📅 预约 | 👤 我的
- **教练 (Role=2)**: 🏠 首页 | 📅 预约 | 💼 **工作台** | 👤 我的
- **管理员 (Role=3)**: 🏠 首页 | 📅 预约 | 📊 **数据看板** | 👤 我的

## **🎨 4. UI 设计与主题建议 (Design Tokens)**

为了给搏击馆营造专业、充满力量感的品牌形象，建议 UI 设计遵循以下风格：

- **主色风格 (Primary Color)**:国际主义极简公务风
- **卡片与边框 (Cards & Borders)**:
  - 使用直角或极小的圆角 (如 border-radius: 4px)，避免过于圆润可爱，保持硬朗风格。
  - 卡片背景采用略浅于底色的深灰色，使用轻微的描边区分层级。
- **排版 (Typography)**:
  - 数据展示（剩余课时、价格、时间）使用加粗的等宽字体（如 DIN Condensed 或系统默认加粗数字），增强数字冲击力。
- **空状态 (Empty States)**:
  - 当没有课程时，不要只写“暂无数据”，可以放一个搏击手套的单色 SVG 图标，配文“今天还没有训练计划，去大厅约一节课吧，汗水不会骗人！”。
